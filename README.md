# EXERCÍCIOS DE APROPRIAÇÃO

**1. Explique o que é uma interface.**
- Uma interface é um contrato de código: ela define quais métodos uma classe deve ter, mas não como eles funcionam.

**2. Qual a diferença entre classe abstrata e interface?** 
- A interface é uma lista de tarefas obrigatórias (o que fazer), enquanto a classe abstrata é uma forma pronta que já vem com pedaços de código e atributos organizados (o que o objeto é).

**3. Por que interfaces ajudam no trabalho em equipe?**
- Ela serve como um acordo combinado entre os programadores: cada um pode codificar sua parte ao mesmo tempo sem travar o colega e sem risco de quebrar o trabalho do outro.
